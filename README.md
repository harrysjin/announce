# 소리 · PDF 장음 표시 스튜디오

[Render로 배포하기](https://render.com/deploy?repo=https://github.com/harrysjin/announce) · [Render 설정 안내](docs/render-deploy.md)

한국어 낭독 대본을 올리고, 사전 발음 근거를 검토하며 실제 음절에 원형 표시를 넣는 웹앱입니다. React/TypeScript + FastAPI/PyMuPDF로 구성했습니다. 애플 스타일의 절제된 작업 공간, 반응형 PDF 뷰어와 설정·검토 패널을 제공합니다. 사전이 연결된 상태에서는 PDF 업로드 후 자동 분석이 시작됩니다. 업로드 전 설정에서 자동 분석을 끌 수 있습니다.

## 사이트 사용 흐름

1. PDF 파일을 선택하거나 작업 공간으로 끌어 놓습니다.
2. 사전이 연결되어 있으면 자동 분석이 시작되고, 진행 상태가 표시됩니다.
3. 검토 목록에서 장단 미확정·뜻 검토 항목을 확인합니다. 항목을 펼친 뒤 ‘원문 위치 보기’로 이동합니다.
4. 색상·크기·불투명도 또는 개별 표시를 수정하고 PDF·검증 기록·CSV를 내려받습니다.

미확정 문맥은 모아 보기에서도 개별 출현으로 유지하며, 뜻이 선택된 동일 항목은 출현 위치를 함께 보여줍니다.
키보드 직접 표시: Tab으로 글자에 진입 → 좌우 방향키로 이동 → Enter/Space로 표시 추가/선택.
완성된 배포 패키지와 실행 절차는 [배포 안내](docs/deployment.md)를 참고하세요.

## 시작하기

Node.js 20.19+/22.12+와 Python 3.10+가 필요합니다. 현재 환경에서는 Node 24/Python 3.12로 검증했습니다.

```bash
cd /workspace/announce
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
npm ci
npm run build
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

이 경우 Python 서버가 빌드된 화면과 API를 함께 제공합니다. `dist/`를 만든 **후에** 서버를 시작하세요. 현재 작업은 기존 체크아웃에서 진행하며 별도 Git worktree는 필요 없습니다.

개발 중에는 터미널 두 개에서 다음 명령을 실행하세요.

```bash
# 터미널 1: Python 가상환경을 활성화한 뒤
npm run server
# 터미널 2
npm run dev
```

Vite(5173)가 `/api` 요청을 Python(8000)으로 전달합니다. 프로세스는 환경 게시·복원 후 자동으로 살아나지 않으므로 다시 시작해야 합니다. 이 프로젝트를 구현하며 배포나 환경 게시는 수행하지 않았습니다.

## 공식 사전 연결

운영 서버에 `STDICT_API_KEY` 환경변수를 안전하게 설정한 뒤 Python 서버를 재시작하세요. 국립국어원 [표준국어대사전 Open API 안내](https://stdict.korean.go.kr/openapi/openApiInfo.do)에서 인증키를 발급받을 수 있습니다. `.env.example`에는 변수 **이름만** 제공합니다. 파일을 자동 로드하지 않으며, 배포 플랫폼의 비밀 환경변수 기능을 권장합니다. 인증키를 브라우저 코드, 저장소, PDF, 로그나 채팅에 넣지 마세요.

제한된 네트워크에서는 `stdict.korean.go.kr`에 대한 HTTPS 요청을 허용해야 합니다. 클라이언트는 기존 프록시와 CA를 사용하고 TLS 검증을 유지합니다. 검색 `search.do`로 후보를, 상세 `view.do`로 발음·의미·활용 정보를 조회합니다. 캐시는 개별 작업의 수명 안에서만 재사용됩니다.

인증키가 없어도 업로드·미리보기·수동 표시·PDF/기록/CSV 내보내기를 사용할 수 있습니다. **사전 연결 대기 상태에서는 자동 판정이 이뤄지지 않습니다.** 실제 사전 응답으로 검증했다는 가짜 예시 결과나 고정 장음 목록을 포함하지 않습니다.

## 구현 범위

- 최대 20MiB, 100페이지의 텍스트형 PDF. 손상·암호 문서 구분, 페이지별 글자/좌표 추출, 스캔·혼합 페이지 식별.
- 페이지 썸네일, 확대·축소, 원문 위치 이동, 음절별 수동 추가·삭제, 표시 위치·개별 크기 보정, 실행 취소·다시 실행, 검토 메모.
- 기본 `#CEE4F5` 원형 표시, HEX/색상 선택기·크기·불투명도 변경. 재분석 없이 미리보기·다운로드에 반영.
- 원문 출현 위치별 검토 목록, 상태·사유 검색, 같은 표현 모아 보기. 동형어 첫 결과 자동 채택 금지. 후보별 발음·한자·뜻·출처 확인 및 의미 선택.
- Kiwi가 원문 문맥에서 기본형·품사·조사/활용 범위를 찾고, 명사+XSV/XSA 파생과 복합어의 원문 음절 범위를 복원합니다. 전체 단어의 직접 발음, 사전에 명시된 활용, 적용 범위가 제한된 규칙 판정을 구분합니다. 원형과 같은 어간+자음 시작 어미만 장단 유지 추론을 허용하며 모음 시작 어미·축약·추가 파생에는 무조건 복사하지 않습니다. 모든 허용 후보가 동의해야 자동 판정하고, 부분 구성 요소 확인은 전체 단음 확정으로 처리하지 않습니다. 선택적인 오타·WikiData 구문 사전은 불러오지 않습니다.
- 전체 추출 어휘/출현 위치를 관리하지만, 조사 결합형·합성어·고유명사·숫자 읽기·문맥 모호성 등은 해결되지 않으면 미확정으로 남깁니다. 사용자 선택과 수동 표시는 자동 검증과 구분합니다.
- `원본이름_장음표시.pdf`, `_장음검증.md`, `_장음목록.csv` 출력. 원문 텍스트·페이지 수·MediaBox/CropBox·회전을 출력 시 검사합니다. 기존 링크·주석을 보존하며 검증 기록은 PDF에도 첨부합니다. 단일 출처 표시는 해당 사전 항목에 연결합니다. 여러 항목의 장단 일치로 표시한 경우 모든 출처를 주석과 검증 기록에 남기며 한 항목을 임의로 대표 링크로 고르지 않습니다.
- 서버가 출력과 같은 글자 ID·좌표·표시 설정을 사용하며, 원형 주석은 Multiply 혼합과 인쇄 플래그를 적용합니다. 겹침·경계 경고는 검증 기록에 포함합니다.
- 실제 진행 단계와 건수, 대기·중단·재시도, 누락된 키·접속 실패·미등재·장단 미확정·뜻 미확정 구분. 분석 동시 실행은 기본 2개이며 `ANALYSIS_CONCURRENCY=1`로 줄일 수 있습니다. Render Free 배포는 1개로 제한하며 대기/처리 시간 한도와 요청 제한이 있습니다.
- 같은 탭에서 새로고침하면 서버에 남아 있는 작업을 복원합니다. 브라우저에는 작업 토큰만 저장하며 PDF 원문은 저장하지 않습니다. 서버 재시작·만료 후 복구는 지원하지 않습니다.

### 현재 한계

OCR, 일반 문맥 의미의 완전 자동 선택, 사전 미제공 활용형의 전체 발음 생성, 줄/페이지 사이에 쪼개진 단어 연결, 서버 재시작 후 작업 영구 복구는 지원하지 않습니다. 같은 철자의 별도 표제어와 조사 결합형이 함께 가능하거나 근거가 부족하면 미확정으로 남깁니다. 일반적인 조사 결합 장음 유지 규칙은 적용하지 않습니다. 현재 형태 분석의 검증·적용 범위와 남은 제약은 [형태소 개선 보고서](docs/morphology-improvement-2026-11-08.md)를 참고하세요. 소규모 회귀 결과는 일반 대본 정확도를 뜻하지 않습니다.

미리보기는 PNG 원문 위에 좌표 기반 SVG를 표시하지만 **다운로드 PDF는 이미지화·재조판하지 않습니다.** 기존 원본의 텍스트와 페이지에 원형 주석을 추가합니다. Chrome 브라우저에서 앱을 검증했으며, macOS 미리보기·Acrobat Reader에서 출력 호환성은 별도 확인이 필요합니다.

## 파일 보관

로그인 없는 단일 임시 작업 공간입니다. 작업 ID는 추측하기 어려운 임의 토큰이며, 파일 목록 API는 없습니다. 파일은 서버 임시 디렉터리에 두고 마지막 접근 후 2시간이 지나면 정리하며(최대 약 1분 정리 주기), ‘작업 삭제’로 즉시 삭제할 수 있습니다. 다른 파일을 열면 이전 작업을 삭제합니다. 서버 재시작 시 복구하지 않습니다. 탭을 닫으면 즉시 삭제되는 방식은 아닙니다. 서버 접근 권한과 HTTPS는 배포 운영자가 관리해야 합니다.

## 검증

```bash
npm run build
python3 -m unittest discover -s tests -v
# 출처를 검증한 소규모 평가 자료 재현 (네트워크 없음)
python3 tests/evaluation.py
# 서버에 실제 사전 키가 연결됐고 Chromium/Playwright가 있는 경우 (실제 API 호출)
python3 tests/live_browser.py --base http://127.0.0.1:8000
```

자동 테스트는 실제 생성한 한글 PDF와 **합성 API 응답**을 사용합니다. 회전·CropBox·링크/주석·텍스트 보존, 수동 수정, 키 누락, 동형어, 명시된 활용 발음, 숫자/소수 읽기 보류와 API 장애를 확인합니다. 합성 사전 응답은 실제 사전 발음 검증 자료가 아닙니다. 검증 범위는 `tests/README.md`와 `docs/improvements-2026-11-05.md`를 참고하세요. 운영 시작 절차는 `docs/deployment.md`와 `scripts/start.sh`에 있습니다. 세션이 프로세스 내부에 있으므로 ASGI worker는 1개만 실행합니다.

PyMuPDF는 AGPL/상용 라이선스를 제공합니다. 배포 형태에 맞는 라이선스를 적용하세요: [공식 안내](https://pymupdf.readthedocs.io/en/latest/about.html).
