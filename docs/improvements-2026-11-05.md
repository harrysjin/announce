# 분석기·검토 화면·운영 기반 개선

보고일: 2026-11-05 (한국 시간). 공개 배포·환경 게시·비밀 값 변경은 수행하지 않았습니다.

## 실제 예시 대본 비교

같은1페이지 예시 대본52개 원문 출현을 공식 사전 API로 다시 조회했습니다.

| 항목 | 이전 시험 | 이번 실제 시험 |
| --- | ---: | ---: |
| 장단을 자동 판정한 출현 | 1 | 14 |
| 장음 출현 / 표시 음절 | 1 / 1 | 4 / 4 |
| 표시 없음 판정 | 0 | 10 |
| 장단 미확정 | 51 | 38 |
| 최종 조회 실패 | 0 | 0 |

이번14개 판정 중12개는 조회된 모든 허용 후보의 장단이 일치한 경우입니다.
이12개에 특정 뜻을 자동 지정하지 않았으며, 문맥 검증 완료로 표시하지 않습니다.
실제 원형 표시는 ‘낭독’의 낭, ‘예시’의 예, ‘천천히’의 첫 천, ‘잠시’의 잠입니다.

Kiwi0.24.1이 문맥에서 품사·기본형·원문 범위를 제안합니다. 형태 분석만으로 발음을 확정하지 않습니다.
활용형과 준말은 공식 상세 응답의 각 발음을 따로 연결합니다. 기본형 장음을 활용형에 복사하지 않습니다.
일반적인 조사 결합 장음 유지 규칙 추론은 적용하지 않았습니다. 실제 발음 근거가 없거나
고유명사·숫자 읽기·후보 간 장단이 모호하면 보류합니다.

실제 결과: `test-results/live-improved/`의 PDF·Markdown·CSV·요약 JSON.
이 실행은 운영 및 기록 보완 이전의 분석기 본체를 검증한 것이며, 이후 근거 메타데이터 보존 수정은 회귀 검사로 확인했습니다.

## 출처를 대조한 소규모 평가

공식 사전 응답을 실제 조회해 저장하고,27개 문맥 표적을 직접 대조했습니다.
14개는 장단 정답을 확인한 표적,13개는 숫자·인명·불명확한 결합형 등 보류 요구 표적입니다.
문장 안의 다른78개 출현은 채점하지 않았습니다.

- 정답 장음9개 음절 중7개 표시,2개는 미확정으로 누락: 재현율7/9.
- 잘못 추가한 장음0개, 표시한 정답 장음7개: 해당 자료에서 정밀도7/7.
- 장단 정답14개 표적 중10개 판정: 판정 범위10/14.
- 보류가 필요한13개 표적 모두 보류.
- snapshot에 없는 조회를 임의로 결과 없음으로 처리한 건수0.

이는 개발용 작은 자료이며 미공개 독립 평가 집합이나 일반 방송 대본 정확도가 아닙니다.
고유명사 모델 판정 오류·뜻 선택·사전 미제공 활용형·줄/페이지 경계 연결·OCR은 추가 개선이 필요합니다.
재현 명령: `python3 tests/evaluation.py --output test-results/evaluation-final`.

## 검토·출력

- 장단 상태와 뜻 상태를 별도로 표시·검색하며, 후보별 근거와 원문 형태의 발음을 함께 보여줍니다.
- 여러 후보의 장단 일치는 전체 후보 ID/출처를 기록하며 특정 뜻풀이를 지어 넣지 않습니다.
- PDF 원형의 출처가 하나면 사전 링크를 연결하고, 여러 출처면 모두 주석/첨부 기록에 보존합니다.
- PDF와 별도 Markdown 기록은 마지막 작업 기록 시각을 사용해 같은 상태에서 일치합니다.
- 메모·색상만 바꿨을 때 사전 근거가 사용자 수동 판정으로 바뀌는 문제를 수정했습니다.
- 실행 취소 시 근거는 서버가 보유한 사전 후보에서 재구성하며 브라우저가 보낸 발음 문자열을 신뢰하지 않습니다.
- 새로고침하면 같은 탭의 임시 작업을 복원합니다. 브라우저에는 원문을 저장하지 않습니다.
- 가이드의 Escape 닫기·키보드 초점 이동을 보완했습니다.

## 운영 기반

- 분석2개 동시 실행, 대기 최대300초·실행 최대600초, 대기 중 수정/내보내기 차단.
- 요청 주소별 업로드30회/분, 분석 시작10회/분 제한. 초과 시429와 Retry-After 반환.
- 진행 조회는 페이지·글자 좌표·사전 본문을 제외한 작은 응답을 사용합니다.
- 중단·시간 초과·예상 밖 오류가 작업을 계속 ‘진행 중’으로 남기지 않도록 정리합니다.
- API 응답은 no-store. 운영 시작 스크립트는 작업 ID를 노출할 URL 접근 로그를 끕니다.
- 단일 프로세스용 시작 스크립트와 배포 안내를 준비했습니다. 다중 인스턴스·공유 저장소 구조는 아닙니다.
- 신뢰할 프록시가 정해지기 전에는 클라이언트가 보낸 전달 주소 헤더를 신뢰하지 않습니다.

소규모 운영의 기반을 검증한 것으로, 실제 공개 인프라의 부하·메모리·프록시 구성 시험을 대신하지 않습니다.
