# 형태 분석·장단음 사전 근거 확인 (2026-11-08)

## 조회 방법과 보존 범위

표준국어대사전 공식 [Open API 설명](https://stdict.korean.go.kr/openapi/openApiInfo.do),
`https://stdict.korean.go.kr/api/search.do`, `https://stdict.korean.go.kr/api/view.do`에
실제 읽기 전용 요청을 보냈다. 환경의 인증키·프록시·TLS 검증을 그대로 사용했다.
인증키와 인증키가 포함된 요청 URL은 기록하지 않았다.

실제 조회 요약은
[morphology_api_schema_2026-11-08.json](../tests/fixtures/morphology_api_schema_2026-11-08.json)에 있다.
조회 시각, 입력어, 검색 방식·대상, 결과 수, 표제어·대상 코드·품사와 상세 발음·활용,
뜻·원어·출처 URL을 보존했다. 이 파일은 임의로 만든 사전 항목이 아니다.
단위 테스트의 `999997` 등 가상 코드는 전송·캐시 계약을 검증하는 별도 자료다.

## 활용 검색 target=5의 확인 결과

공식 API 설명에서 직접 읽은 정의는 다음과 같다.

> 하단의 요청 변수들을 사용하시려면 자세히 찾기 여부(기본값 n)인 "advanced" 요청 변수를 'y'로 하셔야 합니다.

> 찾을 대상(기본값 1) … 1: 표제어 … 5: 활용

> 검색 방식(기본값: exact) … exact: 일치 검색 … include: 포함 검색

`advanced=y`, `method=exact`, `req_type=xml`, `num=100`, `type1=word`로 확인했다.

| 입력어 | 표제어 검색(기본 target=1) | 활용 검색(target=5) |
| --- | ---: | ---: |
| 선발하며 | 0 | 0 |
| 알아 | 0 | 0 |
| 끌어 | 0 | 0 |

상세 응답에 활용으로 명시된 `선발하여`, `선발하니`, `아니`, `끄니`도
이번 `target=5`, `method=exact` 조회에서는 결과 수가 모두 0이었다.
`method=include`로 `알아`, `끌어`, `선발하여`, `하여`, `아`를 검색하거나 `type1`을
생략해도 0이었다. 같은 연결에서 `target=1`, `q=알다`는 1건,
잘못된 대상 `target=99`는 공식 오류 코드 `101`을 반환했다.
따라서 이번에 관찰한 0건을 연결 실패나 오류 응답과 혼동하지 않았다.

문서상 활용 검색은 지원되지만, 이 확인만으로 임의의 어미 결합형을 검색하거나
생성해 주는 기능이라고 볼 수 없다. `lookup_inflections()`는 보조 후보 발견 경로로
제공하되, 직접 표제어 조회를 유지하고 형태 분석으로 복원한 기본형 조회를 병행한다.
검색 결과의 표제어·대상 코드는 발음 근거 자체가 아니다. 해당 `view.do` 상세 응답의
표제어 또는 명시된 활용형이 원문 형태와 정확히 일치해야 사전 직접 발음으로 인정한다.

## 상세 응답에서 확인한 사실

| 상세 표제어 | 대상 코드 | 원어/뜻 구별 | 실제 발음 |
| --- | --- | --- | --- |
| 선발하다 | 184644 | 先發: 남보다 먼저 어떤 일을 시작하거나 길을 떠나다 | 선발하다 |
| 선발하다 | 185215 | 選拔: 많은 가운데서 골라 뽑다 | 선ː발하다 |
| 보도부 | 143839 | 報道部: 보도에 관한 일을 맡아보는 부서 | 보ː도부 |
| 알다 | 213588 | 상세 활용 `알아` | 아라 |
| 끌다 | 403617 | 상세 활용 `끌어` | 끄ː러 |
| 첫눈 | 330923, 489489 | 두 표제어 모두 | 천눈 |
| 밀물 | 130198, 130199, 130201 | 모든 조회 항목 | 밀물 |

표제어별 링크는 예를 들어
[선발하다(先發)](https://stdict.korean.go.kr/search/searchView.do?word_no=184644&searchKeywordTo=3),
[선발하다(選拔)](https://stdict.korean.go.kr/search/searchView.do?word_no=185215&searchKeywordTo=3),
[보도부](https://stdict.korean.go.kr/search/searchView.do?word_no=143839&searchKeywordTo=3)이다.

`보도부`는 현재 실제 사전에 직접 등재되어 있으므로, 구성 요소 추론보다 전체 단어의
직접 발음을 먼저 적용해야 한다. 합성어 분석 자체는 직접 발음 유무와 별개로 시험할 수 있다.
`선발하며`의 기본형을 복원해도 의미 구별이 해결되는 것은 아니다. 전체 사전 후보에
先發/選拔을 모두 포함하면 장단이 상충한다. 選拔 의미가 확인된 회귀 사례의 장음과,
문맥 없는 전체 동형이의어 후보에서의 미확정 판정을 구분해야 한다.

`알아`와 `끌어`는 어근 기본형의 장음을 기계적으로 복사하지 않고 사전의 명시 활용을
써야 한다. `첫눈`·`밀물`은 전체 단어의 직접 발음이 구성 요소의 기본형 발음보다 우선해
오탐을 막는 사례다. 규범 원문을 읽지 못한 상태에서 특정 조항의 예외 목록이라고
단정한 자료로 사용하지 않는다.

## 표준 발음법 제6항·제7항의 검증 경계

표준국어대사전의 메인·도움말을 읽었으나 허용된 호스트 안의 규범 원문 사본이나
관련 내려받기 링크를 찾지 못했다. `kornorms.korean.go.kr` 공식 규범 호스트는
현재 환경의 허용 목록에 없어 프록시가 연결을 거절했다. 이 제한을 우회하지 않았다.
이 문서는 제6항·제7항의 원문을 읽었다고 주장하거나 확인하지 못한 문구를 인용하지 않는다.

규칙은 원문 적용 조건과 예외를 검증한 범위만 활성화해야 한다. 예를 들어 모음 결합,
축약, 접사에 의한 단음화, 복합어의 비첫음절 장음 유지 등을 하나의 '기본형 장음 유지'
규칙으로 처리할 수 없다. 이번 실제 사전 활용 자료는 개별 형태의 발음을 입증하며,
미관찰 형태 전체에 적용되는 규범의 증거를 대신하지 않는다.

원문 접근이 계속 제한된다면 사전 직접 발음·명시 활용을 우선하고, 좁게 정한 형태가
아닌 활용형·접사 파생·불완전한 복합어와 상충하는 동형이의어는 미확정으로 유지한다.
규범 전체의 원문·예외 확인은 남은 검증 항목이다.

## API 어댑터 검증

`tests/test_dictionary_inflection_search.py`를 구현 전에 실행했을 때 3개 테스트가 모두
`lookup_inflections` 미구현으로 실패했다. 구현 후 기존 사전 단위 테스트와 함께 12개가
통과했다. 다음 계약을 확인한다.

- 직접 조회와 보조 조회의 캐시를 분리하고 기존 직접 조회 매개변수를 유지한다.
- 보조 조회는 `advanced=y`, `target=5`, `method=exact`로 검색한 뒤 상세 정보를 가져온다.
- 각 후보에 `lookup_provenance`의 종류·입력어·검색 대상을 남긴다.
- 실제 활용이 없는 검색 hit로 원문의 발음을 만들지 않는다.
- 품사·뜻·발음·출처·조회 시각을 유지하고 네트워크 예외에서 인증키 URL을 노출하지 않는다.
