# 형태 분석 브라우저 통합 검사

검사일: 2026-11-08. 운영 사이트 대신 로컬 Chromium과 루프백 전용 API를 사용했다.
`tests/morphology_browser.py`가 표준국어대사전 실제 응답 snapshot을 재생하는
`ReplayDictionary`를 주입한다. 외부 사전 API나 운영 사이트에 요청하지 않으며,
검사용 서버의 인증키 변수는 가짜 값으로 대체한다. 서버는 검사 종료 시 정리한다.

```sh
npm run build
python3 tests/morphology_browser.py --output test-results/morphology-browser
```

## 범위

- 검색 가능한 한글 PDF를 UI에 업로드하고 자동 분석 완료까지 기다린다.
- 실제 전체 사전 후보로 `선발하며`·`사회혁신융합전공`·`말의`는 미확정,
  `보도부`·`끌어`는 장음, `알아`·`첫눈`·`밀물`은 표시 없음인지 확인한다.
- 복합어 원문 음절 범위, 전체 미확정 안내, 구성요소별 품사·뜻·발음·사전 URL·조회 시각을 확인한다.
- `선발하며`의 실제 選拔 뜻을 사용자가 선택하면 `선`에 표시가 생기고,
  사용자 선택과 규칙 추론의 근거가 구분되어 보존되는지 검사한다.
- 실행 취소·다시 실행 후 규칙 근거·출처·뜻 상태·적용 범위·판정 사유를 비교한다.
  손대지 않은 `보도부`의 자동 판정이 사용자 수정으로 바뀌지 않는지도 검사한다.
- UI 다운로드로 얻은 PDF의 원문·페이지 크기·회전과 모든 원문 글자 좌표가 같은지,
  각 원형 중심이 원래 음절 중심과 0.01pt 미만 차이로 일치하는지 확인한다.
  규칙 출처 URL과 첨부 검증 기록도 확인한다.
- 1440px 데스크톱 및 390px 모바일 화면, 가로 넘침, 브라우저 스크립트 오류를 확인한다.

## 발견과 처리

첫 전체 흐름 검사는 통과했지만, 출처·사유 비교를 강화하면서 실제 회귀를 발견했다.
실행 취소 후 다시 실행하면 `선발하며`의 규칙 판정 사유가 일반 사용자 수정 문구로
바뀌고, 건드리지 않은 자동 단일 후보 `보도부`도 사용자 선택으로 표시되었다.
새 assertion은 구현 수정 전에 이를 실패로 재현했다. 최종 수정 후 재검사 결과는
아래에 기록한다.

최종 재검사: **통과**. 수정 후 전체 흐름과 강화한 출처·사유·미수정 항목 보존 검사를
함께 실행해 약 6.2초에 완료했다. 브라우저 스크립트 오류와 모바일 가로 넘침은 없었다.

## 산출물

`test-results/morphology-browser/`에 `analysis.json`, 데스크톱 구성요소·선택 화면,
모바일 화면, 다운로드 PDF 및 렌더링 이미지를 저장한다. 원문 예시는 이 검사에서
생성한 8개 표현의 PDF이며, 일반 대본 정확도나 독립된 언어학 평가 결과를 뜻하지 않는다.

다운로드 PDF의 육안 검사에서는 `선발하며`의 `선`, `보도부`의 `보`, `끌어`의 `끌`에
원형이 있고, `사회혁신융합전공`·`알아`·`첫눈`·`밀물`·`말의`에 잘못된 원형이 없었다.
