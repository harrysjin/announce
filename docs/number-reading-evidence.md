# 숫자 읽기와 원문 표시의 검증 근거

2026-11-09 작업 기록. 구현은 `backend/numbers.py`, 초기 회귀는
`tests/test_numbers.py`, 독립 경계 사례는 `tests/test_numeric_edge_cases.py`에 있다.
숫자 읽기 표에는 수사의 철자와 자릿값만 저장한다. 장음 여부를 숫자값별로 저장하거나
예제 표현의 정답으로 대체하지 않는다.

## 공식 사전과 발음 규칙

검증 자료는 국립국어원 [표준국어대사전 Open API](https://stdict.korean.go.kr/openapi/openApiInfo.do)의
검색 및 상세 응답을 저장한 `tests/fixtures/numeric_dictionary_2026-11-08.json`이다.
검색 결과는 표제어 발견에 사용하고, 장음은 상세 응답의 `pronunciations` 필드로 판단한다.
후보에는 표제어, 품사, 한자/원어, 뜻풀이, 발음, 공식 항목 URL, 조회 시각을 보존한다.
인증키 값은 fixture나 보고서에 저장하지 않는다.

| 확인 내용 | 공식 상세 응답의 구분 | 처리 |
|---|---|---|
| `2`를 이로 읽기 | 수사 二/貳, `[이ː]` | 선택된 읽기에서 원문 `2`의 한 글자 대응을 확인한다. |
| `4`를 사로 읽기 | 수사 四, `[사ː]` | 沙/砂·絲 등 동음 표제어를 제외한다. |
| `5`를 오로 읽기 | 수사 五, `[오ː]` | 수사의 실제 발음을 사용한다. |
| 두·세·네 | 고유어 관형사, `[두ː]`·`[세ː]`·`[네ː]` | 二·三·四의 발음을 대신 쓰지 않는다. |
| 다섯 | 고유어 수사/관형사, `[다섣]` | `5개`를 선택했을 때 장음 표시를 만들지 않는다. |
| 이십·사십·오십 | 완성된 수사 二十·四十·五十의 상세 발음 | 구성 요소 추론보다 해당 표제어의 직접 근거를 먼저 사용한다. |

예를 들어 이의 수사 二 후보와 수사 釐 후보는 품사가 같아도 의미가 다르다.
한자까지 일치하는 후보만 수사의 장단 근거에 포함한다. 고유어는 고유어 품사를 따로 확인하며,
여러 허용 후보의 장단이 상충하거나 발음이 없으면 보류한다.

표제어 전체가 등재되지 않은 복합 수사는 구성 요소를 각각 조회한다.
[표준 발음법 제6항](https://kornorms.korean.go.kr/regltn/regltnView.do?regltn_code=0002)의
단어 첫음절 범위를 하나의 선택된 복합 수사 안에 적용한다. `24`의 이십사에서
뒤쪽 사의 기본형 `[사ː]`를 원문 `4`에 그대로 복사하지 않는다. 이 경우 결과의 근거 유형은
`numeric_rule`이며, 적용 조항과 구성 요소별 원래 발음, 유지한 위치, 비첫음절에서 제외한 위치를
함께 남긴다. 구성 요소 발음 목록은 실제 전체 수사의 사전 발음인 것처럼 제시하지 않는다.

## 읽기 선택과 의미 구분

| 표현 종류 | 생성하는 읽기 | 자동 확정의 범위 또는 보류 이유 |
|---|---|---|
| 일반 정수 | 한자어 수사, 가능한 고유어 수사, 식별 번호 읽기 | 맥락이 없는 숫자는 사용자가 선택한다. 한자어는 16자리까지, 고유어는 1~99 범위다. |
| 명·개 등 수량 단위 | 일반적인 고유어 관형형과 한자어 대안 | 실제 품사·단위 근거와 장음 위치가 확인되어야 한다. |
| 번 | 번호의 한자어 읽기와 횟수의 고유어 읽기 | 같은 줄에 두 의미가 함께 올 수 있어 `버스` 같은 줄 전체 단서로 자동 선택하지 않는다. |
| 분 | 시간 分과 사람을 높여 세는 고유어 분 | 사용자 선택이 필요하다. `3분`은 삼 분/세 분에서 장단 결과도 달라질 수 있다. |
| 연도 | 자릿값을 적용한 한자어 읽기와 年 단위 | 전체 수사 또는 구성 요소의 공식 근거로 검증한다. |
| 달력의 월·일 | 월/일의 숫자 읽기 후보 | 달력의 월 이름과 기간 단위 월을 혼동하지 않는다. 월 이름 전체·단어 경계 근거가 부족하면 선택 후에도 보류한다. |
| 금액 | 한자어 수사 + 현대 원 | 3자리 쉼표를 검증하고 원문 위치를 유지한다. 현대 원에 옛 圓/元 또는 일본 엔의 뜻풀이를 붙이지 않는다. |
| 백분율 | 수사 + 퍼센트 | `%` 한 글자를 퍼센트 세 음절과 일대일 대응시킬 수 없다. 공식 발음 누락 등은 보류한다. |
| 소수 | 정수부 + 점 + 소수부 각 자리, 0의 영/공 대안 | 소수점·단위·낭독 경계의 실현을 자동 확정하지 않는다. |
| 콜론 시각 | 1~12시 고유어, 0~23시 한자어, 각 자리 읽기 대안 | `13:04`에 열세 시를 생성하지 않는다. 없는 시·분·초 글자는 원문 글자에 대응시켰다고 주장하지 않는다. |
| 전화번호·식별자 | 각 자리 읽기, 0의 공/영 대안 | 끊어 읽는 경계와 장음 실현을 사용자가 검토해야 한다. |
| 제… 순번 | 접두사 제-와 한자어 수사 | 접두사를 포함한 실제 단어의 장음 범위와 위치는 별도 검토한다. |

`365일`처럼 달력 날짜의 범위를 넘더라도 기간 읽기 후보는 남긴다.
`02분`처럼 앞자리 0이 있으면 0을 버리지 않으며, 후보에도 원문의 분 단위를 유지한다.
`6월`과 `10월`은 육월·십월로 자동 생성하지 않고 유월·시월의 실제 어형과 위치 대응을 보류한다.

## 원문 숫자와 발음 음절 대응

모든 `source_start/source_end`는 원문 표현의 문자 오프셋이고,
`reading_start/reading_end`는 선택한 한국어 읽기의 음절 오프셋이다.
`24`의 이십사에서 이는 `2` 한 글자에 정확하게 대응하지만,
십은 자릿값을 나타내므로 한 숫자 글자의 발음이라고 처리하지 않는다.
`20,004원`의 사는 쉼표를 제외한 새 문자열의 위치가 아니라 원문 `4`의 위치 5에 대응한다.

장음 위치를 원문에 표시하려면 해당 발음 음절을 덮는 대응 항목이 정확히 하나여야 한다.
그 항목이 발음 한 음절 ↔ 원문 숫자 한 글자의 `exact=true` 대응이어야 한다.
겹치는 대략적 대응이 있거나, 원문 위치가 단위·기호이거나, 음절과 숫자가 여러 대 여러이면
임의의 숫자를 고르지 않는다. 따라서 열/쉰 같은 고유어 십 단위나 만의 장음을
`10`/`50`/`10000`의 한 숫자에 추정하여 옮기지 않는다.

콜론 시각의 시·분·초는 삽입된 발음이므로 원문에서 길이 0의 경계에 연결하고
`exact=false`로 기록한다. `02:04`의 사는 뒤쪽 실제 `4` 위치에 연결한다.
자리수를 줄인 정수 문자열의 위치를 그대로 원문 위치로 쓰지 않는다.

부분 근거가 있어도 전체 읽기나 위치가 확정되지 않으면 결과는 `unresolved`이며
표시 위치는 빈 목록이다. 이미 확인한 후보 ID·공식 발음·구성 요소 근거·적용 규칙은
보류 결과에서도 보존한다. 사용자가 기본 제안과 같은 읽기를 직접 선택해도 선택 출처는
`user`로 기록한다.

## 검증과 남은 제한

독립 검토 후 경계 사례 테스트를 먼저 작성해 실행했다. 최초 12개 메서드 실행은
16개의 실패 사건을 기록했다. 여기에는 같은 테스트의 시·분·초 및 잘못된 날짜 하위 사례가
포함되며, 16개의 서로 다른 테스트 메서드라는 의미는 아니다.
이후 의미 구분·대응 수정과 기간 읽기 회귀를 보강했다.

```sh
python3 -m unittest discover -s tests -p 'test_numbers.py' -v
python3 -m unittest discover -s tests -p 'test_numeric_edge_cases.py' -v
python3 -m unittest discover -s tests -p 'test_numeric_api.py' -v
```

직접 실행한 숫자 모듈 검증은 기존 12개와 경계 사례 17개가 통과했다.
읽기 선택·재분석·이력·원문 위치·내보내기를 검증하는 숫자 API 테스트 6개도 통과했다.
경계 사례에는 1~3999의 숫자별 정확한 대응 항목 불변식과 만·억·조의 4자리 그룹 검사가 포함된다.
이 검사는 숫자 생성과 위치를 검증하며, 모든 숫자의 장음 발음을 사전으로 전수 검증했다는 뜻은 아니다.

남은 자동 처리 제한은 다음과 같다.

- 달력의 월 이름 전체 발음, 유월·시월 어형, 월/일의 실제 단어 경계.
- 전화번호·식별자·소수·콜론 표기의 실제 낭독 경계와 장음 실현.
- 장음 한 음절을 원문 숫자 한 글자로 확정할 수 없는 자릿값·고유어 읽기.
- 공식 상세 발음이 빠진 외래 단위, 뜻/품사/한자가 맞지 않는 단위, 후보 간 장단 충돌.
- 16자리를 넘는 한자어 정수, 99를 넘는 고유어 수사, 부호·지수·분수·다른 통화 기호 등 지원 문법 밖 표현.

이 범위에서는 표시를 추정하지 않고 이유와 검토 가능한 읽기 후보를 제공한다.
실제 PDF 추출·화면·이력·PDF 재출력 보존 검증은 별도의 API 및 PDF 테스트가 담당한다.
