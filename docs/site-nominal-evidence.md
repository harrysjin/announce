# 조사 결합 명사의 장단 근거

`보도부를`의 기본형을 찾아도 기존 `form_evidence`는 동사·형용사의 자음 시작 어미만 처리하므로 장음 표시를 만들지 못했다. 실제 Kiwi 분석은 문맥에 따라 `보도부/NNG + 를/JKO` 또는 `보도/NNG + 부/NNG + 를/JKO`로 달라진다. 이제 두 경우 모두 원문에 연속해서 나타나는 명사 전체 `보도부`를 사전 조회 기본형으로 복원한다.

장단 유지 추론은 다음 조건을 모두 만족할 때 적용한다.

- 사전 후보에 명시적인 `명사` 또는 `의존 명사` 품사가 있다.
- 후보의 표제어가 분석된 명사 전체와 일치하며 원문 글자가 그대로 이어진다.
- 뒤의 모든 형태소가 `J*` 조사이며, 각 형태소의 글자와 시작·끝 좌표가 원문에 정확히 일치한다.
- 모든 허용 후보에 발음 근거가 있고 장음 위치가 일치한다. 상충하거나 발음이 빠진 후보가 있으면 보류한다.

결과는 기본형 발음 `[보ː도부]`, 기본형 발음 범위 `보도부`, `source=rule`, `evidence_type=rule_inference` 또는 `rule_consensus`로 기록한다. 조사까지 합친 발음 문자열을 생성하지 않는다. 적용 규칙에는 표준 발음법 제6항과 원문 조사 경계를 연결한 설명을 기록하며, 조사 결합 자체의 직접 사전 발음으로 제시하지 않는다. 기본형 후보의 정의·한자·품사·공식 URL·조회 시각도 보존한다.

직접 확인된 실제 형태의 발음은 유지 추론보다 우선한다. `말의`의 전체 표제어와 조사 결합 해석이 겹치는 경우와 `말을`의 실제 후보 장단이 상충하는 경우는 계속 보류한다. 계사 `VCP`, 접미사 `XSN`, 어미, 어간 변화, 겹치거나 빠진 형태소 경계에는 이 명사 유지 규칙을 적용하지 않는다. 품사가 없는 이전 합성 fixture도 명사 유지 근거로 사용하지 않는다.

`NNP` 표지는 완전한 명사 범위에 대한 가설로 유지한다. 공식 사전의 같은 전체 명사 표제어가 확인되면 `보도부/NNP + 를/JKO`에도 동일한 검증을 적용한다. `기쁨 씨`처럼 호칭이 이어지는 인명 문맥은 기존 보호 조건으로 보류한다. 분석기가 하나의 알 수 없는 고유명사만 제안한 경우 임의 접두어를 잘라 조회하지 않으며, 이 변경은 일반적인 인명·보통명사 의미 구별을 해결하지 않는다.

숫자와 띄어 쓴 단위 분석을 위해 각 occurrence 계획에는 같은 줄의 다음 형태소 최대 8개(`following_tokens`, 원문 occurrence 시작 상대 문자 좌표)와 뒤 문맥 최대 80자(`trailing_context`)도 제공한다. 기존 글자·음절 좌표와 PDF glyph ID는 변경하지 않는다.

## 검증

소스 수정 전에 새 단위·계획 검사 8개를 실행해 5개 실패를 확인했다. 실패는 기본형 장음 유지·후보 합의가 `None`을 반환하는 경우와, 자연스러운 조사 결합 및 `NNP` 계획이 각각 `compound`·`proper`로 남는 경우였다.

수정 후 다음 명령으로 새 검사 13개와 기존 형태소·규칙 경계 검사 총 35개가 통과했다.

```sh
PYTHONPATH=.:tests python -m unittest test_nominal_particle_evidence test_morphology_regression test_rule_boundaries -v
```

새 PDF 검사는 회전된 검색 가능 한국어 PDF에서 원래 첫 `보`의 glyph ID를 표시하는지, 원문 글자·페이지 배치가 보존되는지, 출력 주석에 조사 규칙 근거가 포함되는지 확인한다. 사전 근거는 `morphology_regression_dictionary_2026-11-08.json`과 이전 공식 응답 snapshot을 재생하며, 현재 API 접속이나 보편적인 문맥 판정 정확도를 주장하지 않는다. 이 실행 환경의 sandbox에서 asyncio wakeup이 멈추는 기존 제약 때문에 통합 검사는 sandbox 밖에서 실행했다.
