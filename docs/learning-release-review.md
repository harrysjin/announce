# 장음 학습 관리 사이트: 검토와 운영 연결

## 사용자가 검토할 항목

| 항목 | 현재 구현 | 검토할 내용 |
| --- | --- | --- |
| 학습 문맥 | 동의한 이후의 수정만 수집. 대상 표현과 주변 문맥 최대 160자 저장. 원본 PDF·파일명·전체 페이지·자유 메모는 저장하지 않음 | 주변 문맥 저장 범위가 대본의 개인정보와 사용 목적에 맞는지 |
| 본인 기록 식별 | 로그인 없이 브라우저의 HttpOnly 쿠키로 구분. 본인 조회·내보내기·전체 삭제 제공 | 쿠키를 지우거나 다른 브라우저를 쓰면 기존 기록에 재접근하기 어려운 방식으로 1차 운영할지 |
| 검수자 | 서버의 별도 관리자 인증키로 인증. 의미와 발음·장음 위치를 따로 승인 | 우선 단일 관리자 방식으로 운영할지. 다중 관리자 계정·로그인은 별도 범위 |
| 장기 DB와 비용 | 운영 PostgreSQL 연결 전. 웹 서비스의 기존 Free 설정은 유지 | 보유한 PostgreSQL을 연결할지, 장기 운영 DB를 새로 선택할지 |

Render 공식 문서 기준 Free Postgres는 생성 후 30일에 만료되고 추가 유예 기간 뒤 삭제된다. 장기 학습 기록 저장소로 무료 DB의 무기한 보존을 전제하지 않는다. 2026-11-10 확인한 Render 요금표의 최소 유료 Postgres 컴퓨트는 월 US$6부터이며 저장 공간 등 추가 비용은 생성 화면에서 확인해야 한다. 이 작업에서 유료 DB 생성·결제·요금제 변경은 수행하지 않는다.

- 무료 DB 제한: https://render.com/docs/free
- 현재 요금표: https://render.com/pricing

## 구현된 이용 화면

- `/`: 기존 PDF 작업 공간. 분석·표시·취소·출력 정책 유지.
- `/learning`: 학습 관리 전용 주소. 직접 접속·새로고침·브라우저 뒤로 가기 지원.
- 근거 펼치기: 선택한 뜻·읽기, 사전 발음, 원문 표시 글자, 확인 범위, 적용 규칙, 당시 후보·공식 사전 링크 표시.
- 숫자: 선택한 읽기 음절과 원문 숫자의 대응을 표시. 정확한 대응 여부를 구분.
- 수정 이력: 변경 전후의 뜻·읽기·표시를 문장으로 확인. 상세 원본 JSON은 별도 펼치기.
- 수동 표시와 뜻 선택을 공식 사전 검증 완료로 제시하지 않음. 근거 부족 사례는 추가 검수 유지.

## 운영 연결 순서

현재 준비된 소스는 `feature/learning-audit-phase1`, 검토 대상은 PR #1이다. 원래 요청의 실제 배포 금지 조건을 유지하므로 `main` 병합과 공개 배포는 별도로 진행한다.

1. Render 계정을 연결하고 실제 `sori-studio` 서비스와 공개 주소를 확인한다. 서비스 이름만으로 URL이나 서비스 ID를 추측하지 않는다.
2. 영구 PostgreSQL을 선택한다. 비용이 발생하는 리소스는 요금·저장 공간·지역을 확인한 뒤 생성한다. 기존 DB 연결도 가능하다.
3. 다음 값은 서버의 비밀 환경변수로 설정한다. 인증키·DB 주소의 비밀값은 저장소나 채팅에 붙여 넣지 않는다.

| 환경변수 | 값의 조건 |
| --- | --- |
| `DATABASE_URL` | 선택한 PostgreSQL 연결 문자열. 외부 접속은 공급자의 TLS 설정 사용 |
| `LEARNING_DOCUMENT_KEY` | 32자 이상 난수. 관리자 인증키와 다른 값. 장기 운영 중 보존 |
| `LEARNING_ADMIN_TOKEN` | 32자 이상 난수. 검수자가 사용할 인증키 |
| `LEARNING_ADMIN_ID` | 예: `primary-reviewer`. 검수 이력에 기록할 식별명 |
| `LEARNING_PUBLIC_ORIGIN` | 실제 공개 HTTPS origin. 예시 값이나 `/learning` 경로를 넣지 않음 |

4. DB 접속이 가능한 운영 도구 또는 개발 PC에서 정확한 기능 브랜치의 가상환경을 사용해 아래 명령을 실행한다. `.env`는 자동으로 읽지 않으므로 비밀값은 실행 프로세스에 안전하게 주입한다. 마이그레이션 계정과 앱 계정이 다르면 각각의 권한으로 확인한다.

```sh
python -m backend.learning_db
python -m backend.learning_setup
```

첫 명령은 명시적으로 스키마를 적용한다. 둘째 명령은 읽기 전용으로 인증키 설정 여부, HTTPS origin, DB 접속, 마이그레이션 버전·체크섬, 대상 테이블의 조회·저장·수정·삭제 권한을 확인한다. 비밀값·연결 주소·사용자 기록은 출력하지 않는다. 준비되면 종료 코드 0, 설정이 부족하면 종료 코드 2를 반환한다. 점검 명령은 `/api/health`나 PDF 분석에서 자동 실행하지 않는다.

5. 테스트가 통과한 소스와 설정을 적용한 뒤 `/api/health`, `/api/learning/status`, `/learning`을 확인한다. 운영 DB가 준비되기 전에는 학습 저장 성공으로 안내하지 않는다. 운영 사용자의 기록을 승인 없이 생성·삭제하는 방식으로 점검하지 않는다.
