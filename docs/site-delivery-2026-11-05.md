# 소리 사이트 제작·전달 기록

2026-11-05 (한국 시간). 기존 분석기를 실제 사용자 흐름과 배포 가능한 웹앱으로 마무리했습니다.
공개 인터넷 배포·환경 게시·API 비밀 값 변경은 수행하지 않았습니다.

## 이용 흐름

- 텍스트형 PDF 선택/끌어 놓기 → 사전 연결 상태에서 자동 분석 → 검토 → 다운로드.
- 업로드 전 설정에서 자동 분석을 끄면 원문을 먼저 열고 직접 표시할 수 있습니다.
- PC는 썸네일·PDF·설정/검토 패널, 모바일은 대본/검토 탭으로 사용합니다.
- 검토 항목을 펼치면 후보·메모가 그대로 보이고 ‘원문 위치 보기’로 별도 이동합니다.
- 뜻이 미확정인 같은 표현은 모아 보기에서도 서로 다른 출현으로 유지합니다.
- 뜻과 읽기가 같은 선택 항목은 묶고, 그룹 안에서 각 출현 위치를 선택할 수 있습니다.
- 다운로드 메뉴는 분석 전 여부와 표시·장단 미확정·뜻 미확정 개수를 보여 줍니다.
- 표시와 글자에 키보드로 접근할 수 있습니다. 글자는 Tab 진입 후 좌우 방향키, Enter/Space로 조작합니다.
- 저장 실패 때 설정을 복원하고, 실행 취소 실패 때 기존 기록을 유지합니다.
- 일반 이용 가이드에는 운영자용 환경변수 설정 대신 사용 흐름과 사전 연결 상태를 안내합니다.

## 검증

- 프로덕션 프런트 빌드와 Python 회귀49개 통과.
- 실제 사전 브라우저 시험: PDF 업로드가 자동으로 분석 요청을 발생시키며, PC·모바일에서 검토·수정·새로고침 복귀·다운로드 성공.
- 외부 사전 요청 없는 제품 흐름 검사: 미확정 문맥 분리, 모바일 상세/원문 이동, 실패한 저장/실행 취소 복구, 키보드 글자 이동·표시, 분석 전 출력 상태, 작업 삭제 통과.
- PC1440×1100과 모바일390×844에서 초기 화면·가이드·가로 넘침·Escape 닫기를 확인했습니다.
- 알 수 없는 API 경로는 HTML 성공 응답 대신404 JSON을 반환합니다.
- `scripts/release-check.sh`가 빌드·회귀 검사·별도 포트 서버 시작·health·정적 파일·예시 PDF 응답을 검증합니다.
- Docker 이미지에서 실제 사전 분석 완료와 표시4개 생성, PDF·MD·CSV 내보내기, 원문 보존·검증 기록 첨부, 작업 삭제 후404를 확인했습니다.

실행 명령과 컨테이너 검증 정보는 `docs/deployment.md`에 있습니다.
브라우저 검사: `tests/live_browser.py`, `tests/product_workflow.py`.
화면: `test-results/site-preview/desktop.png`, `mobile.png`.

## 지원 범위

텍스트형 PDF 최대20MiB·100페이지, 임시 작업1개 중심의 검토 보조 서비스입니다.
현재 자동 장단 판정은 모든 문맥의 검증 완료를 의미하지 않습니다. 장단 상태와 뜻 상태를 구별하며
근거가 부족한 표현은 미확정으로 남깁니다. 일반 문맥의 완전 자동 의미 선택, OCR, 영구 보관,
여러 서버 인스턴스 간 작업 공유, macOS 미리보기·Acrobat 호환성 확인은 완료 범위가 아닙니다.

## 전달·공개 운영

소스·설정·검사·Docker 배포 파일을 배포 패키지 ZIP으로 제공합니다.
API 키·환경 비밀 값·업로드 PDF·개발 의존성 폴더·임시 분석 결과는 ZIP에 포함하지 않습니다.
현재 클라우드의 내부 실행과 외부 공개 사이트는 구별됩니다. 공개 주소를 만들려면 Python/Docker를
실행할 호스팅 계정과 운영 비밀 설정이 필요합니다. 공개 배포는 이번 작업에서 수행하지 않았습니다.
