## 규칙의 적용 범위

전체 표제어/실제 활용 발음이 가장 우선이다. 규칙 판정은 사전 직접 발음으로 표시하지 않으며
기본형 발음을 원문 전체의 발음처럼 생성하지 않는다. 예시 단어별 정답 목록은 엔진에 넣지 않았다.

| 범위 | 처리 |
|---|---|
| 제6항 첫음절 장단 | 원문과 같은 어간+자음 시작 어미의 확인된 장단 위치만 연결. |
| 제6항 합성어 | 첫 구성 요소의 일치 근거를 연결하되, 뒤 구성 요소의 장음은 일괄 단음화하거나 무조건 복사하지 않고 전체 근거 없으면 미확정. |
| 제6항 모음 축약 | 실제 형태의 사전 발음 없으면 보류. |
| 제7항 모음 시작 어미 및 단음화 예외 | 기본형으로부터 생성하지 않고 명시 활용 발음 우선. 알아 [아라], 끌어 [끄ː러]는 실제 상세 응답으로 검증. |
| 제7항 추가 피동·사동 파생, 어간 교체 | 유지 추론 제외. 사전 실제 형태의 근거 필요. |

공식 규범 호스트는 환경 허용 목록 밖이어서 원문 접속이 제한됐다. 제6·7항 전체 원문·예외를
이번에 모두 대조했다고 주장하지 않는다. 제한된 규칙 외 확대는 이 검증이 남아 있다.
네트워크 초안에 `kornorms.korean.go.kr`, PR용 `api.github.com`을 추가하려 했으나
`draft_not_editable`로 저장되지 않았다. 현재 설정과 서비스는 바꾸지 않았다.

## 남은 미확정 범위

상충하는 동형이의어, 미등재 구성 요소, 복합어 비첫음절의 장음, 미관찰 모음 결합·축약·어간 교체,
불명확한 조사 결합, 숫자 읽기와 OCR은 이 단계의 자동 판정 범위 밖이다.
Kiwi 품사 오분석 또는 target=5 연결 실패도 판정 범위를 줄일 수 있다. 결과와 제외 후보를 남겨 검토할 수 있다.
실제 target=5는 이번에 조회한 활용형에서 HTTP200/0건이었으므로 임의 활용형 생성기로 간주하지 않았다.
MD의 별도 후보 표는 뜻을 자동 선택한 결과가 아니다. [내보내기 검증 해석](morphology-export-evidence.md) 참고.
